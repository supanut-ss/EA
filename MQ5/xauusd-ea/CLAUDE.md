# XAUUSD EA Project — Context for Claude Code

ผู้ใช้สื่อสารภาษาไทย ให้ตอบเป็นภาษาไทย โค้ดและ log ใช้ภาษาอังกฤษได้

## เป้าหมาย
- EA บน MetaTrader 5 เทรด **XAUUSD เท่านั้น**
- ออกไม้บ่อย วันละหลายรอบ กำไรประมาณ $10–20 ต่อรอบ ในระยะวิ่งไม่เกินประมาณ 500 จุด
- ไม่เปิด lot หนักในไม้แรก

## ข้อตกลงทางเทคนิค
- ภาษา **MQL5**, บัญชี **Hedging**
- **1 จุด = $0.01 ของราคาทองเสมอ** (100 จุด = $1) EA ต้องปรับเองสำหรับโบรก 2 หรือ 3 ทศนิยม
- ทอง 0.01 lot ราคาขยับ $1 = กำไร/ขาดทุน $1 (contract size 100)
- ไฟล์ .mq5 บันทึกเป็น **UTF-8 with BOM** (มีคอมเมนต์และ input ภาษาไทย ถ้าไม่มี BOM MetaEditor จะแสดงผิด)
- สถานะ EA ต้องอ่านจากออเดอร์จริงด้วย Magic Number (ทำงานต่อได้หลังรีสตาร์ท)
- **ยังไม่เคยคอมไพล์จริง** ทุกไฟล์ต้องคอมไพล์ตรวจก่อน
  - Windows: `"C:\Program Files\MetaTrader 5\metaeditor64.exe" /compile:"path\file.mq5" /log` แล้วอ่านไฟล์ .log ข้างกัน

## ระบบที่กำลังพัฒนา: Stop Grid v2
วาง pending 6 ไม้ ระยะเท่ากันทั้ง 2 ฝั่ง รอบจุดกลาง P
- ผังเดิม: Buy Stop +100/+200/+300 และ Sell Stop −100/−200/−300, lot 0.01/0.03/0.05, TP ±500, SL ที่ P
- ผังทางเลือก A: 200/400/500 TP700 | B: 100/300/500 TP600
- SL ที่ P อยู่ก่อนไม้แรกของอีกฝั่ง จึงไม่มีไม้สองฝั่งล็อกกันค้าง

## ข้อสรุปจากการวิเคราะห์ (สำคัญ)
- ถ้าราคาสุ่ม **ค่าคาดหวังต่อรอบ = $0 ทุกผังและทุกลำดับ lot** แล้วติดลบจาก spread (ประมาณ $0.6–0.9 ต่อรอบที่ spread 20 จุด)
- ผังเดิม: ถึง TP 20% (+$23), SL1 50% (−$1), SL2 16.7% (−$7), SL3 13.3% (−$22)
- ผัง A: TP 28.6% (+$24), SL1 50% (−$2), SL2 10% (−$14), SL3 11.4% (−$39)
- ผัง B: TP 16.7% (+$19), SL1 66.7% (−$1), SL2 13.3% (−$10), SL3 3.3% (−$35)
- ล็อกกำไร (+400 → SL +300) ลดความผันผวน แต่ไม่เพิ่มค่าคาดหวัง
- **กำไรต้องมาจากจังหวะวาง** (ราคาวิ่งต่อเนื่องมากกว่าการสุ่ม) ผังเดิมต้องถึง TP ≥ 23% จึงคุ้มต้นทุน เป้าคือ ≥ 25%
- ตรวจตรรกะจำลองของสคริปต์กับ random walk แล้ว ได้ TP ~21% ใกล้ทฤษฎี

## สถานการณ์ที่จะทดสอบ (สมมติฐาน ยังไม่พิสูจน์)
- S1 กรอบเอเชีย (00:00 UTC → ก่อนลอนดอนเปิด 15 นาที) กว้าง ≤ 500 จุด
- S2 บีบตัว: กรอบ 120 นาที ≤ 400 จุด ช่วงลอนดอนเปิดถึง 20:00 UTC
- S3 กรอบ 40 นาทีก่อนนิวยอร์กเปิด ≤ 300 จุด
- ผลแยกตามทิศเทรนด์ EMA200 H1 และตามชั่วโมง (เวลาไทย UTC+7)
- ไม่ควรวาง: ไซด์เวย์เหวี่ยงกว้าง, ก่อนข่าวแรง, หลังราคาวิ่งแรงไปแล้ว, ดึกหลัง NY, เปิดจันทร์/ปิดศุกร์, spread สูง

## ข้อจำกัดของสคริปต์เฟส 0
- ไม้ติดตรงราคาที่วาง ไม่มี slippage (ผลดีกว่าจริง)
- ลำดับราคาในแท่ง M1: แท่งเขียว O→L→H→C, แท่งแดง O→H→L→C
- โซนเวลา default: server GMT+2/+3 ตาม DST อเมริกา, ลอนดอนตาม DST อังกฤษ
- `skipped` สูงในโหมด RANGE_MID = ราคาเลยไม้แรกไปแล้วตอนวาง ให้ลองรันซ้ำด้วย CENTER_PRICE

## คำถามที่ยังค้างกับผู้ใช้
- เวลา server ของโบรก (GMT offset)
- spread/คอมมิชชันจริงของบัญชี
- ชุด lot ×1 (0.01/0.03/0.05) หรือ ×2 (0.02/0.06/0.10)
- OppositeMode ค่าเริ่มต้น: KEEP หรือ DELETE
- ผังระยะไม้ที่ต้องการจริง (เดิม / A / B)
