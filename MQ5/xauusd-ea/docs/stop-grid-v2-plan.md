# วิเคราะห์ระบบ Stop Grid 6 ไม้ และแผนใหม่ (XAUUSD)

> ใช้เพื่อวางแผนและทดสอบเท่านั้น ไม่ใช่คำแนะนำการลงทุน ตัวเลขทุกตัวต้องยืนยันด้วยข้อมูลจริงก่อนใช้เงินจริง
> หน่วย: 100 จุด = $1 ของราคาทอง | 0.01 lot ขยับ $1 = กำไร/ขาดทุน $1

---

## 1. สรุปผลวิเคราะห์ (อ่านส่วนนี้ก่อน)

1. **ผังไม้และลำดับ lot ไม่ได้สร้างความได้เปรียบ** ถ้าราคาเคลื่อนแบบสุ่ม ค่าคาดหวังต่อรอบคือ $0 พอดี แล้วหักด้วย spread และ slippage จึงติดลบเล็กน้อยทุกรอบ
2. **ชนะเต็มรอบแค่ประมาณ 20%** ผลที่เจอบ่อยที่สุดคือเสีย $1 (ครึ่งหนึ่งของรอบ) ระบบนี้คือ "แพ้เล็กบ่อย ชนะใหญ่นานๆ ครั้ง" ซึ่ง **ตรงข้าม** กับเป้า "ออกไม้กำไรบ่อยๆ"
3. **กำไรจริงต้องมาจากจังหวะวาง** คือวางเฉพาะตอนที่ราคามีโอกาสวิ่งต่อเนื่องสูงกว่าการสุ่ม เช่น หลังตลาดบีบตัวแล้วเข้าช่วงลอนดอน/นิวยอร์ก
4. **ต้องชนะเต็มรอบอย่างน้อยประมาณ 23%** จึงคุ้มค่า spread และควรได้ 25% ขึ้นไปจึงคุ้มค่าเสี่ยง
5. **ดังนั้นแผนใหม่เริ่มจากวัดสถิติจากข้อมูลจริงก่อน** ถ้าทองไม่มีพฤติกรรมวิ่งต่อหลังบีบตัวถึงระดับนี้ การเขียน EA เต็มระบบก็ไม่คุ้ม

## 3. ความน่าจะเป็นแต่ละผล (ถ้าตลาดสุ่ม)

คิดเฉพาะฝั่งที่ติดก่อน ใช้หลักว่าราคาสุ่มจากจุด A จะไปถึง B ก่อน C ด้วยสัดส่วนระยะทาง ตรวจสอบซ้ำด้วยการจำลองแล้ว

| ผลของรอบ | ความน่าจะเป็น | กำไร/ขาดทุน |
|---|---|---|
| ติด 1 ไม้ แล้วกลับ P | 50.0% | −$1 |
| ติด 2 ไม้ แล้วกลับ P | 16.7% | −$7 |
| ติด 3 ไม้ แล้วกลับ P | 13.3% | −$22 |
| ถึง TP ครบ 3 ไม้ | **20.0%** | **+$23** |
| **ค่าคาดหวัง** | | **$0.00** |

**ต้นทุน:** lot เฉลี่ยที่เปิดจริงต่อรอบประมาณ 0.042 lot ถ้า spread 20 จุด เสียเฉลี่ย **$0.83 ต่อรอบ** ยังไม่รวม slippage ของ stop order

### ลองสลับ lot เป็น 0.05 / 0.03 / 0.01 (ไม้ใหญ่ก่อน)

| ผล | ความน่าจะเป็น | กำไร/ขาดทุน |
|---|---|---|
| ติด 1 ไม้ | 50.0% | −$5 |
| ติด 2 ไม้ | 16.7% | −$11 |
| ติด 3 ไม้ | 13.3% | −$14 |
| ถึง TP | 20.0% | +$31 |

ผลคือค่าคาดหวังยังเป็นศูนย์ แค่เปลี่ยนรูปการกระจายกำไรขาดทุน จึงยืนยันว่า **lot ไม่ใช่ตัวสร้างกำไร**

## 5. ความได้เปรียบต้องมาจากไหน

ระบบ stop order ได้กำไรเมื่อ **ราคาวิ่งต่อเนื่องหลังเริ่มขยับ** มากกว่าการสุ่ม สมมติฐานที่ควรทดสอบกับทองคำ:

| สมมติฐาน | เหตุผล | วิธีวัด |
|---|---|---|
| หลังบีบตัว ราคามักขยายตัว | ความผันผวนมักสลับช่วงแคบ-กว้าง | กรอบ 8 แท่ง M15 < 400 จุด แล้ววัดผล |
| ช่วงตลาดลอนดอน/นิวยอร์กเปิด วิ่งต่อเนื่องกว่า | สภาพคล่องและคำสั่งใหญ่เข้าตลาด | แยกสถิติตามชั่วโมง |
| วางตามทิศเทรนด์ใหญ่ ได้ผลกว่า | เบรกตามเทรนด์หลอกน้อยกว่า | แยกสถิติตาม EMA200 H1 |
| ช่วงเอเชียมักหลอก | สภาพคล่องต่ำ | เทียบผลช่วงเอเชียกับช่วงอื่น |

**ความไวของกำไรต่ออัตราชนะ** (ประมาณการ lot ชุด ×1 หลังหัก spread $0.83)

| อัตราถึง TP | กำไรเฉลี่ยต่อรอบ | 5 รอบ/วัน × 22 วัน |
|---|---|---|
| 20% (สุ่ม) | −$0.8 | −$90 |
| 23% | +$0.5 | +$55 |
| 25% | +$1.4 | +$155 |
| 30% | +$3.7 | +$400 |

> ตัวเลขนี้เป็นภาพประกอบ ถ้าใช้ lot ชุด ×2 (0.02/0.06/0.10) ทุกตัวเลขคูณ 2 รวมถึงขาดทุน

## 6. ความเสี่ยงเฉพาะของระบบนี้

| ความเสี่ยง | ผลกระทบ | วิธีรับมือ |
|---|---|---|
| Slippage ของ stop order | ได้ราคาแย่กว่าที่วาง โดยเฉพาะตอนข่าว | ลบ pending ก่อนข่าว, จำกัด spread, เทสบัญชี demo ของโบรกจริง |
| ราคากระโดดข้ามหลายระดับ | ติด 3 ไม้พร้อมกันที่ราคาแย่ | ห้ามวางช่วงข่าว, ช่วงเปิดตลาดวันจันทร์ |
| Spread กว้างชั่วคราว | Buy Stop ติดเพราะ Ask พุ่งแม้ราคาไม่ได้วิ่งจริง | ลบ pending เมื่อ spread เกินค่า |
| Stops Level ของโบรก | วางไม้แรกที่ 100 จุดไม่ได้ | EA เช็คก่อนวาง ถ้าไม่ได้ให้ขยายระยะทั้งชุด |
| แพ้ติดกันนาน | ต่อ 10 รอบ มีโอกาสไม่ชนะเลยประมาณ 11% | ทุนต้องรับขาดทุน 10 รอบ (ประมาณ $58 ที่ lot ×1) ได้สบาย |
| ตลาดเหวี่ยงไซด์เวย์ | ติดไม้ 1–2 แล้วโดน SL ซ้ำๆ | ตัวกรองบีบตัว + จำกัดจำนวนรอบที่แพ้ติดต่อกันต่อวัน |

**ทุนแนะนำ:** lot ×1 อย่างน้อย $1,000 | lot ×2 อย่างน้อย $2,000

## 8. สเปก EA v2 (ร่าง)

### สถานะของระบบ

| สถานะ | ความหมาย | ไปสถานะถัดไปเมื่อ |
|---|---|---|
| IDLE | ไม่มีไม้และ pending | ผ่านเงื่อนไขวางทุกข้อ → ARMED |
| ARMED | วาง 6 pending แล้ว | ไม้ติด → ACTIVE, หมดเวลา/ข่าว/spread สูง → ลบทั้งหมด → IDLE |
| ACTIVE | มีออเดอร์เปิดอยู่ | ถึง TP หรือ SL ครบทุกฝั่ง → DONE |
| DONE | จบรอบ | บันทึกผล, ลบ pending ที่เหลือ, รอแท่ง M15 ถัดไป → IDLE |

### เงื่อนไขวางชุด pending (ต้องผ่านทุกข้อ)
1. สถานะ IDLE และขึ้นแท่ง M15 ใหม่
2. อยู่ในช่วงเวลาที่กำหนด (ค่าเริ่มต้นตามผลเฟส 0)
3. กรอบ High–Low ของ `SqueezeBars` แท่ง ต่ำกว่า `SqueezeMaxRange` จุด
4. Spread ต่ำกว่า `MaxSpread`
5. ไม่อยู่ในช่วงข่าว, ไม่ใช่หลังเวลาตัดวันศุกร์, ไม่ใช่ช่วงเปิดวันจันทร์
6. ยังไม่ถึง Daily Loss และจำนวนรอบแพ้ติดกันยังไม่เกิน `MaxLossStreakPerDay`

### จุดกลาง P
- `CenterMode = RANGE_MID` (ค่าเริ่มต้น): กึ่งกลาง High/Low ของกรอบบีบตัว
- `CenterMode = PRICE`: ราคาปัจจุบัน
- ตรวจว่าไม้แรกทั้ง 2 ฝั่งห่างราคาปัจจุบันมากกว่า Stops Level ไม่งั้นข้ามรอบนี้

### การจัดการระหว่างรอบ
- ฝั่งหนึ่งติดไม้แรก → ตามค่า `OppositeMode`
  - `KEEP` (ค่าเริ่มต้น): คง pending ฝั่งตรงข้ามไว้ รับกรณีเบรกหลอกแล้ววิ่งกลับ
  - `DELETE`: ลบทิ้ง ความเสี่ยงต่อรอบต่ำลง
- ราคาถึง `LockTrigger` → เลื่อน SL ทุกไม้ฝั่งนั้นไป `LockLevel`
- Pending ค้างเกิน `PendingExpiryMin` นาทีโดยไม่มีไม้ติด → ลบแล้วกลับ IDLE
- ก่อนข่าวหรือ spread เกิน → ลบ pending ที่ยังไม่ติด (ไม้ที่เปิดแล้วถือต่อด้วย TP/SL เดิม)
- เปิด MT5 ใหม่ → อ่านสถานะจาก pending และออเดอร์จริงด้วย Magic Number

### ตาราง Input

| Input | ค่าเริ่มต้น | หมายเหตุ |
|---|---|---|
| `LotSequence` | `0.01,0.03,0.05` | lot ของไม้ 1–3 ต่อฝั่ง |
| `LotScale` | 1.0 | ใส่ 2.0 = ชุด 0.02/0.06/0.10 |
| `LevelSequence` | `100,200,300` | ระยะจาก P (จุด) |
| `TPDistance` | 500 | จาก P |
| `SLDistance` | 0 | 0 = SL ที่ P |
| `LockTrigger` / `LockLevel` | 400 / 300 | 0 = ไม่ใช้ |
| `OppositeMode` | KEEP | KEEP / DELETE |
| `CenterMode` | RANGE_MID | RANGE_MID / PRICE |
| `SqueezeBars` | 8 | แท่ง M15 |
| `SqueezeMaxRange` | 400 | จุด |
| `SessionStart` / `SessionEnd` | 14 / 23 | ปรับเป็นเวลา server ของโบรก |
| `PendingExpiryMin` | 120 | |
| `MaxSpread` | 25 | จุด |
| `TrendFilter` | OFF | OFF / EMA200 H1 (วางเฉพาะฝั่งตามเทรนด์) |
| `MaxLossStreakPerDay` | 4 | แพ้ติดกันครบ หยุดวันนั้น |
| `DailyLossPct` | 5 | |

## 9. เกณฑ์ตัดสินใจ

- **เฟส 0 หาเงื่อนไขที่ถึง TP ≥ 25% ไม่ได้** → หยุดระบบนี้ กลับไปพัฒนา grid v1.1 ต่อ หรือลองสมมติฐานอื่น
- **ผ่านเฟส 0 แต่ backtest หลังหักต้นทุนติดลบ** → ตรวจ slippage และ spread ก่อน แล้วลองขยายระยะห่างไม้เพื่อลดผลของต้นทุน
- **ผ่านทุกเฟส** → เพิ่ม lot ทีละขั้น (×1 → ×1.5 → ×2) ทุกขั้นต้องผ่านอย่างน้อย 1 เดือน

- [ ] ชุด lot ×1 หรือ ×2
