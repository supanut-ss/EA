# สเปก Grid EA v1.1 (XAUUSD)

> เป้าหมาย: เก็บกำไรทีละ 200–400 จุด ออกไม้บ่อย โดยใช้ grid ที่มีระบบคุมความเสี่ยงเป็นแกนหลัก
> สถานะ: ร่างเพื่อใช้เขียนโค้ด ค่าทุกตัวต้องยืนยันด้วย backtest ก่อนใช้งานจริง

---

## 1. สภาพแวดล้อม

| หัวข้อ | ค่าที่กำหนด |
|---|---|
| แพลตฟอร์ม | MetaTrader 5 (MQL5) |
| ประเภทบัญชี | Hedging (ต้องถือ buy/sell พร้อมกันได้) |
| สินค้า | XAUUSD เท่านั้น (EA ปฏิเสธการรันบน symbol อื่น, รองรับ suffix เช่น XAUUSDm) |
| Timeframe ตัวกรองเทรนด์ | H1 |
| Timeframe สัญญาณและ ATR | M15 |
| การทำงาน | ตรวจเงื่อนไขทุก tick, เปิดไม้แรกเฉพาะตอนแท่ง M15 ใหม่ |
| ทุนขั้นต่ำแนะนำ | $2,000 ต่อ 0.01 lot เริ่มต้น (หรือบัญชี Cent) |

> **เรื่องหน่วยจุด:** ใน EA นี้ 1 จุด = 0.01 ของราคาทองเสมอ (300 จุด = $3.00)
> EA ปรับให้อัตโนมัติ ทั้งโบรก 2 ทศนิยมและ 3 ทศนิยม รวมถึง Spread และ Slippage

---

## 2. ตรรกะการเข้าไม้แรก

EA เปิดได้ครั้งละ 1 ชุดไม้ (basket) ต่อฝั่ง และเทรดตามเทรนด์เท่านั้นเป็นค่าเริ่มต้น

**ฝั่ง Buy เปิดไม้แรกเมื่อครบทุกข้อ**
1. ราคาปิด H1 อยู่เหนือ EMA(200) H1
2. RSI(14) M15 ต่ำกว่า 40 (ย่อตัวในเทรนด์ขาขึ้น)
3. ผ่านตัวกรองทั่วไป (หัวข้อ 6)
4. ยังไม่มี Buy basket เปิดอยู่

**ฝั่ง Sell** กลับด้าน: ต่ำกว่า EMA(200) และ RSI สูงกว่า 60

**โหมดเสริม (ปิดไว้ก่อน): Range mode** เปิดได้ทั้งสองฝั่งเมื่อ ADX(14) H1 < 20

## 3. การเพิ่มไม้ตาม Grid

- **ระยะ grid** = `ATR(14, M15) × GridATRMult` แล้วบีบให้อยู่ระหว่าง `MinGridStep` ถึง `MaxGridStep`
- คำนวณระยะใหม่ทุกครั้งที่จะเปิดไม้ถัดไป (grid ขยายเองเมื่อตลาดเหวี่ยงแรง)
- เปิดไม้ถัดไปเมื่อราคาวิ่งสวนจากไม้ล่าสุดเกินระยะ grid
- ต้องห่างจากไม้ก่อนหน้าอย่างน้อย `MinMinutesBetween` นาที
- หยุดเพิ่มเมื่อถึง `MaxOrdersPerSide` หรือ lot รวมเกิน `MaxTotalLot`
- ไม่เพิ่มไม้ถ้า Drawdown ปัจจุบันเกิน `NoNewOrderDD%`

**ขนาด lot ของไม้ที่ n**

```
Lot(n) = BaseLot × LotMultiplier^(n-1)   ปัดลงตาม Lot Step ของโบรก
```

- `BaseLot` ตั้งตายตัว หรือคำนวณจากทุน: `Balance / LotPerBalance × 0.01`
- `LotMultiplier` จำกัดไม่เกิน 1.3 (ล็อกในโค้ด)

## 4. ตรรกะการปิดไม้

| สถานการณ์ | วิธีปิด |
|---|---|
| มีไม้เดียว | TP ของไม้ = `TP_Points` (200–400) |
| มี 2 ไม้ขึ้นไป | ยกเลิก TP รายไม้ แล้วตั้ง TP ร่วมที่ `ราคาเฉลี่ยถ่วง lot ± BasketTP_Points` |
| ทางเลือกเสริม | ปิดทั้ง basket เมื่อกำไรรวม ≥ `BasketTP_Money` (0 = ปิดใช้งาน) |
| Trailing (ปิดไว้ก่อน) | ไม้เดียวกำไรเกิน `TrailStart` ให้เลื่อน SL ตามทีละ `TrailStep` |

---

## 5. ระบบคุมความเสี่ยง (ห้ามปิด)

| กลไก | ค่าเริ่มต้น | การทำงาน |
|---|---|---|
| Equity Stop | 20% | Equity ต่ำกว่า Balance เกินค่านี้ → ปิดทุกไม้ของ EA ทันที |
| หยุดเปิดไม้ใหม่ | 12% | Drawdown เกินค่านี้ → ไม่เพิ่มไม้ รอออก basket |
| Daily Loss Limit | 8% | ขาดทุนสะสมวันนี้เกิน → หยุดเทรดถึงวันถัดไป |
| Cooldown หลัง Equity Stop | 24 ชม. | กันการเข้าซ้ำในตลาดที่ยังผิดทาง |
| Basket อายุยาวเกิน | 72 ชม. | แจ้งเตือน (ออปชันปิดทิ้งได้) |
| Max Total Lot | 0.30 | ต่อ $2,000 ทุน |

## 6. ตัวกรองทั่วไป

- **Spread** สูงสุด: `MaxSpread` points (ไม่เปิดไม้แรกและไม่เพิ่มไม้)
- **ช่วงเวลาเทรด:** เซิร์ฟเวอร์ 09:00–22:00 (ปรับได้)
- **เลี่ยงช่วงเปิดตลาดใหม่:** ไม่เปิดไม้ใหม่ 30 นาทีแรกของวันจันทร์ และ 60 นาทีหลังตลาดเปิดรายวัน
- **วันศุกร์:** ไม่เปิด basket ใหม่หลัง 18:00 และมีออปชันปิดทั้งหมดก่อนตลาดปิด
- **ช่วงข่าว:** ใส่ช่วงเวลาห้ามเทรดเองผ่าน input (MT5 Calendar ใช้ใน Strategy Tester ไม่ได้)

## 7. ความทนทานของโค้ด

- Magic Number แยกต่อ EA และต่อ symbol
- เปิด MT5 ใหม่หรือเน็ตหลุด → EA อ่านสถานะจากออเดอร์ที่เปิดอยู่แล้วทำงานต่อได้ (ไม่เก็บสถานะในตัวแปรอย่างเดียว)
- ตรวจ `SYMBOL_TRADE_STOPS_LEVEL`, filling mode และ margin ก่อนส่งคำสั่ง
- ส่งคำสั่งซ้ำสูงสุด 3 ครั้งเมื่อ requote / off quotes
- บันทึก log ทุกการเปิด ปิด และเหตุผลที่ตัวกรองบล็อก
- แผงข้อมูลบนกราฟ: จำนวนไม้แต่ละฝั่ง, lot รวม, ราคาเฉลี่ย, จุด TP ร่วม, DD ปัจจุบัน, สถานะตัวกรอง

## 9. เกณฑ์ผ่าน Backtest (ก่อนไปเฟส Demo)

- ช่วงทดสอบอย่างน้อย 2–3 ปี ด้วย Every tick based on real ticks และต้องมีช่วงเทรนด์แรงอยู่ด้วย
- Max Equity Drawdown ต่ำกว่า 25%
- Profit Factor มากกว่า 1.3
- Recovery Factor มากกว่า 3
- Equity Stop ทำงานไม่เกิน 1 ครั้งต่อ 6 เดือน
- ผล Forward test (ข้อมูลที่ไม่ได้ใช้ optimize) ไม่แย่กว่า backtest เกิน 30%
- เฉลี่ยออกไม้ได้อย่างน้อย 1–3 ครั้งต่อวัน (ตรงเป้า "ออกไม้บ่อย")
